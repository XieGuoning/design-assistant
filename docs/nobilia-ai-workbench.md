# 中文空间设计工作台

入口：[打开网页源码](../web/nobilia/index.html)。网页参考用户提供的 nobilia.ai 表单截图，采用独立的中文界面，不是 nobilia 官方产品。

## 打开方式

将仓库下载或拉取到本机，用 Chrome 打开 `web/nobilia/index.html` 即可使用。页面的样式、脚本与插画均包含在单个 HTML 文件中，无需安装 Node、Python 或前端依赖，无需网络即可整理需求。

如果浏览器限制打开本地文件，也可在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，再打开 `http://127.0.0.1:8765/web/nobilia/`。退出时用Ctrl+C关闭服务。

如果从 GitHub 浏览仓库，文件页面展示的是源码。下载 `index.html` 后在浏览器打开即可看到工作台；GitHub 文件链接不是已部署网站。本次未配置 GitHub Pages 或其他公开托管。

## 功能

- 厨房、卫浴、起居空间切换；配色、饰面、台面／家具材质、风格、建筑类型与景观可自由填写。
- 暖木自然、现代极简、柔和奶油三种搭配预设。所有候选值为本工作台建议，未核实为 nobilia.ai 的完整下拉选项。
- 支持选择或拖入 PNG、JPEG、WebP 图片；最大12 MB、4000万像素。图片仅在当前浏览器预览，不发送到服务器。
- 从需求出发的空间灵感模式，以及保留原图视角、门窗、柜体与家具的模型图模式。未选择模型图时，提示词明确要求补充原图。
- 实时生成中文设计提示词；支持复制、下载 TXT、导出 JSON、导入 JSON，以及主动保存／恢复当前浏览器的草稿。
- 浏览器限制剪贴板时自动选中提示词，供手动复制。浏览器限制本地存储时提示改用 JSON 导出。
- 参考图片的导出记录仅包含文件名、类型、大小、像素尺寸，不包含图片内容。导入／恢复需求后须重新选择图片。
- 官方网站入口与仓库内的柏丽技术资料、模型图转效果图说明。

## 使用流程

1. 选择空间，填写配色与材质，选择设计方式。
2. 有模型图时选择“基于模型图”，附上导出的模型截图、白模图或透视线稿。SKP、DWG、Carat 原生工程需先在对应软件导出图片。
3. 复制提示词给本项目助手，并同时附上原始图片。助手按 [模型图转效果图流程](model-to-render.md) 检查当前会话的图像工具，实际生成后复核结果。
4. 或点击 nobilia.ai 官方链接，在官方网页中选择其实际提供的选项并生成。此工作台不会自动提交需求或登录网站。
5. 需要柏丽实际选型时，使用 [nobilia 2026 技术资料](../knowledge/nobilia-2026.md)，核对门板编号、柜型、尺寸、台面与安装条件。AI 图片不能确认可订货组合。
6. 保存图片、需求、生成工具与复核记录。生成前导出的方案状态固定为 `prepared_not_rendered`。

## 数据与兼容性

建议使用当前版本的 Chrome。采用标准浏览器能力，没有外部字体、脚本、统计或后台请求。官方链接由用户点击后打开。

草稿只有点击“保存本机草稿”才写入当前浏览器的本地存储，键名为 `design-assistant.space-brief.v1`；默认不自动恢复。共享设备上可通过浏览器清除该页面的站点数据；删除文件并不等于清除浏览器草稿。“重置”仅清空当前填写内容，保留已保存草稿。

导入仅接受本工作台导出的版本1 JSON，校验空间、模式、文本类型和长度。导入内容中的旧提示词、生成状态、后台名称与图片路径不会执行或用于连接服务；提示词根据需求重新生成。

本次未取得 nobilia.ai 的已核实公开 API 或官方源码。网页不包含图像生成模型，没有接通 nobilia.ai，也不会自动启用收费服务。实际图像生成通过助手当前可用工具或官方网页完成，须如实标明来源。

在仓库根目录运行：

```bash
node --test tests/test_space_brief.cjs
```

测试覆盖需求导出／导入、错误格式拒绝、超长及不完整字段、模型图缺失提示、空间切换语义，以及忽略导入的生成状态与执行内容。测试直接读取 HTML 中的数据逻辑；不代表已在用户手机或桌面浏览器中实测所有交互。

2026-10-14 已通过6项数据与静态脚本测试，并在本地HTTP预览中用Chromium验证空间切换、搭配预设、模型图缺失提示、图片预览、草稿保存／恢复、JSON导出／导入、无效JSON处理、复制反馈，以及1440px桌面和390px手机视口布局。测试没有浏览器运行错误，也没有向外部网站发送请求。模拟手机视口不等于在用户实际手机上运行验证；本环境浏览器策略阻止 `file://`，因此交互验证使用临时本地HTTP服务，完成后已关闭。
