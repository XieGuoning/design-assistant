# 模型图转效果图

## 输入
必需：一张模型截图、白模图或透视线稿（PNG、JPEG、WebP）。
可选：风格、墙地顶/家具材质、光照时段、参考图、允许改变的项目。
模型图是编辑目标；风格/材质图仅作辅助参考，不以参考图布局替换原布局。
SKP、DWG、Carat 原生工程须先在对应软件导出图片；本流程不解析原生三维模型。

## 执行步骤
1. 查看原图，识别相机视角、空间边界、门窗、柜体、家具位置。输入无法辨认时索取清晰图片。
2. 检查会话中是否有图像生成/编辑工具。没有时如实说明限制；可继续整理准备包，但不能声称已生成。
3. 使用当前运行时的图像技能和工具说明。内置工具无需用户提供 API 密钥，不应假设每个云端环境都有此工具。
4. 可运行 prepare_render.py 整理输入信息与提示词。查看原图后补充实际观察到的结构约束；脚本不会识别房间结构。
5. 调用图像编辑工具，传入模型图作为编辑目标；辅助图单独标注角色。保持画幅和相机视角，按要求增加真实材质、灯光、阴影与反射。
6. 查看生成结果，和原图逐项比对。出现门窗消失、墙体改变、家具移动、柜门数量改变或透视扭曲时，针对偏移重新生成；无法消除的偏移需说明。
7. 将选定结果复制到 outputs/renders/ 的新文件名；同时保存最终提示词与复核记录。不要只留下工具缓存路径。实际尺寸以输出文件为准，不能把放大图片称作原生高分辨率生成。

## 能力边界
这是 AI 图像编辑工作流，不是 V-Ray、Enscape、Cycles 等基于完整三维场景的确定性渲染器。锁定结构属于生成约束，不能保证毫米级精度。需要准确几何、工程尺寸或稳定多视角时，应使用原模型的专业渲染流程。
若用户明确选择 API 接入，可另行配置运行时支持的图像 API；本次配置不包含 API 密钥、不自动启用计费服务。
