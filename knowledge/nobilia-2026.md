## 查询方法

在仓库根目录运行（查询只需 Python 3 标准库）：

```bash
python3 tools/nobilia.py search 'Easytouch 945' --limit 5
python3 tools/nobilia.py search '转角 地柜' --chapter 03 --limit 5
python3 tools/nobilia.py search 'worktop overhangs' --chapter 10 --limit 5
python3 tools/nobilia.py page 09 243
python3 tools/nobilia.py verify
```

`search --chapter` 按手册章节筛选；`page` 第一参数是原始**文件编号**，第二参数是该文件内**PDF页码**。检索结果给出原文件、PDF页、印刷页候选和摘录。印刷页候选为文本匹配，须核对页脚。关键词检索支持常见中文词映射，不是完整中文翻译或语义模型；无结果时改用英文术语、完整型号或 `rg -n -i 'keyword' data/nobilia/2026/pages`。

需要查看图表时：

```bash
mkdir -p outputs/nobilia
pdftoppm -f 243 -l 243 -scale-to 2200 -png -singlefile data/nobilia/2026/pdf/09_More_than_kitchen.pdf outputs/nobilia/worktop-overhangs
```

再用会话的图片查看工具打开生成的 PNG。PDF 原件保存全部图形；逐页文本未做 OCR，33页少于80个文本字符（含分隔页、空白页和图像页），清单有 `needs_visual_review` 标记。其他页面的表格也不保证抽取后列关系正确。

## 回答与证据规则

1. 先检索，再读完整命中页面及相关脚注。回复中文，保留厂家英文系列、完整型号、后缀和单位。
2. 尺寸图、订货表、价格组、开门方向与兼容性必须回看PDF页面，不能将邻列数值或图示标注直接拼成规格。明确区分柜体高、门板高、踢脚高、总高及台面厚度。
3. Points、PG/Price groups 不等于人民币或欧元售价。报价需另有币种、点值换算、折扣及税费依据。
4. 型号、尺寸、门板颜色、LINE N兼容性、特殊制作、区域限制和安装条件以对应版本的正文、图例及脚注为准。章节交叉引用必须继续核对；缺资料时明确指出。
5. 答复附“文件名 + PDF页码 + 已核对的印刷页码”；引述图表时保留相关备注。对产品选型可继续组合门板、柜体、台面和安装条件，不宣称所有组合均已人工核验。
6. 这是2026版资料快照。库存、现行价格、后续产品变更未联网更新。资料库不是模型训练，不保证在无此项目或仓库访问的其他聊天中自动记忆。

## 补录与维护

将取得的完整原始00–09文件放入一个目录，执行：

```bash
.venv/bin/python tools/nobilia.py build /path/to/source-pdfs
python3 tools/nobilia.py verify
python3 -m unittest discover -s tests -p 'test_nobilia.py' -v
```

默认要求10份齐全；仅明确保留缺口时用 `--allow-incomplete`。当前第10章定位按已核实09文件的PDF第185页开始，换版时必须复查此边界。拆分上传的06/08应按用户说明的原页序重组，再导入；不要根据字典排序猜测顺序。原文件内容变动时脚本拒绝覆盖，需为新版本建立独立目录。清单含每份PDF及每页文本SHA-256，便于校验。
