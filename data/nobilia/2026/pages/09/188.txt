                                                              Information on ordering front panels
Components
Front panels




                   Symbols for front panels    In the column "For use as" six symbols identify the intended purpose of the respective front dimensions.


                                               SK      Identifies individual fronts, which can be used as a drawer.



                                                A      Identifies individual fronts, which can be used as a pull-out.



                                                T      Identifies individual fronts, which can be used as a hinged door.


                                                K      Identifies individual fronts, which can be used as a flap and a swivel flap.



                                                L      Identifies individual fronts, which can be used as a lifting door.



                                               FL      Identifies individual fronts, which can be used as a folding-lifting door.



                                                B      Identifies individual fronts, which can be used as a front panel.
