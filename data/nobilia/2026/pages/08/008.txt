                                     Product Features & Planning Information


Horizontal recessed handle C and L profiles
• L profiles are generally used beneath the worktop on base units and beneath
  the top shelf on highboards.
• The recessed handle with C profile is used between the fronts on base and
  tall units.




  L profile                                  C profile



Transition between base units and tall units with horizontal recessed handles
• When base units are planned adjacent to tall units and the aim is to create
  a continuous visual line of recessed handles, a hairline gap is formed in
  the profile at the transition between the L profile of the base unit and the
  C profile of the tall unit. If this is considered bothersome, an upright should
  be planned at the end of the base unit.




Blank cuts, Milled holes / pockets
• For visible carcase sides on base and tall units, both profile versions are
  provided with a milled pocket.
• Adjacent base units are milled through to achieve a continuous profile line.
• If the end of run is planned with a front upright or end upright, the last
  carcase side is milled through and the recessed handle ends at the upright.
• L profiles beneath induction hobs can be milled in three lengths:
  550 / 750 / 850 mm. The milled depth is 5 mm. The necessary width will be
  determined based on the hob ordered. It is absolutely necessary that the
  appliance information is included in the order.
• Milling is not necessary for appliances from the BSH (Bosch, Siemens, Neff,
  Junker) and Electrolux group (AEG, Electrolux, Progress) or for hot plates of
  the brands Miele, Bora, Beko and Elica.




                                                                                    Optional lighting of the vertical recessed handle
                                                                                    • Vertical recessed handles at the ends and between units on highboards and
                                                                                      tall units can be equipped with LED light design MP-NGMS at a surcharge.
                                                                                    • A surcharge is calculated per recessed handle.
                                                                                    • The following special features must be taken into account when planning
                                                                                      housings for ovens, microwaves, steam ovens and compact appliances:
                                                                                    			         - The lighting can only be installed opposite the fixing strip.
                                                                                    			         - Not possible with end recessed handle NGMA*.
                                                                                    			         - Not possible between two housings.
                                                                                    • It is not possible to retrofit LED lighting (MP-NGMS).
